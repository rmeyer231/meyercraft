# Safety & Parental Settings

## Multiplayer Safety

If your son ever connects to online servers (not just LAN):

**In Minecraft:**
- Options → Chat Settings → set to **Commands Only** to disable player chat
- Options → Multiplayer → **Server Resource Packs: Prompt** (don't auto-accept)

**Microsoft Account Parental Controls:**
- Go to https://account.xbox.com/settings
- Under the child's account, you can:
  - Block multiplayer entirely
  - Block communication with strangers
  - Require approval for friend requests
  - Set play time limits

**In the Minecraft launcher:**
- Profanity filter is on by default for child accounts
- Chat reporting is built into Java Edition 1.19.1+

## Safe Mod Downloads

**Only download mods from:**
- https://modrinth.com (best)
- https://www.curseforge.com/minecraft
- GitHub releases from the mod author

**Never download from:**
- 9minecraft.net
- minecraftmods.com
- Any site that makes you go through multiple "download" buttons or ad pages
- These sites repackage mods with malware

**If you suspect a bad mod:**
- Delete it from the mods folder immediately
- Run a malware scan
- Check https://stopmodreposts.org for a list of known bad sites

## LAN Play (Safest Option)

For playing together at home, LAN is the simplest and safest:
1. Both computers must be on the same WiFi network
2. Player 1: Open a singleplayer world → press Escape → **Open to LAN**
3. Player 2: Multiplayer → the LAN world appears automatically
4. No port forwarding, no online exposure, no strangers
