# Quick Start Guide

## The Fastest Path to Playing as Monsters

### Step 1: Install Prism Launcher (5 min)

1. Go to [https://prismlauncher.org](https://prismlauncher.org) and download for your OS
2. Install and open it
3. Log in with your Microsoft/Minecraft account

### Step 2: Create a Modded Instance (2 min)

1. Click **"Add Instance"**
2. Select the latest Minecraft version (e.g., 1.21.x)
3. Under **Mod Loader**, select **Fabric** → pick the latest Fabric loader version
4. Name it "Meyercraft" → click **OK**

### Step 3: Install Mods (5 min)

1. Right-click your "Meyercraft" instance → **Edit** → **Mods**
2. Click **"Download Mods"** (searches Modrinth + CurseForge)
3. Search for and add each of these (it handles dependencies automatically):
  - `Identity` — the main "play as mobs" mod
  - `Sodium` — FPS boost
  - `Lithium` — performance
  - `Mod Menu` — configure mods in-game
  - `Iris Shaders` — if you want pretty shaders
4. Click **OK** to download all

### Step 4: Play! (0 min)

1. Double-click the instance to launch
2. Create a new world (enable cheats if you want commands)
3. Kill a mob
4. Press `**~`** (tilde key) to open the Identity menu
5. Select the mob → you ARE the mob now

### Pro Tips

- **Can't find tilde key?** It's top-left of the keyboard, below Escape. You can rebind it in Options → Controls.
- **Want ALL mobs unlocked immediately?** With cheats on, use: `/identity grant @s minecraft:ender_dragon` (or any mob name)
- **Want to grant all at once?** Install the mod, go to `.minecraft/config/identity/` and edit the config to unlock all by default
- **Dying while transformed?** You keep your identity — you just respawn as that mob
- **Want a challenge?** Mobs are hostile to you when you look like their enemy. Zombies will attack if you're a skeleton!
