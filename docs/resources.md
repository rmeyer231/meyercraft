# Minecraft Modding Resources

## Mod Download Sites (Safe & Trusted)

| Site | URL | Notes |
|------|-----|-------|
| **Modrinth** | https://modrinth.com | Best mod site — fast, clean, verified uploads |
| **CurseForge** | https://www.curseforge.com/minecraft | Largest mod library, used by most modpacks |
| **Fabric Mod List** | https://fabricmc.net/wiki/community:mods | Official Fabric community mod directory |
| **GitHub** | https://github.com | Many mods host source + releases on GitHub |

> **WARNING:** Avoid random Google results and sketchy mod sites (9minecraft, minecraftmods.com, etc.) — they reupload stolen mods and bundle malware. Stick to Modrinth and CurseForge.

## Useful Commands (Vanilla)

These work in any single-player world with cheats enabled:

```
/gamemode creative          — fly, unlimited blocks, invincible
/gamemode survival          — normal mode
/gamemode spectator         — fly through walls, invisible, possess mobs (click on them)
/difficulty peaceful        — no hostile mobs
/give @s diamond_sword 1    — give yourself items
/effect give @s speed 9999 5 — permanent speed boost
/tp @s 0 100 0              — teleport
/time set day               — skip night
/weather clear              — stop rain
/kill @e[type=!player]      — kill all mobs nearby
```
