# Meyercraft

A custom Minecraft Java Edition mod setup focused on **playing as any mob** with full abilities.

Kill a creeper → become a creeper → explode things.
Kill a bat → become a bat → fly around.
Kill an ender dragon → become the ender dragon → rain destruction.

## Setup

Uses **Minecraft Java Edition** with the **Fabric** mod loader. The core mod is **[Identity](https://modrinth.com/mod/identity)** by Draylar.

The easiest way to get going is to install [Prism Launcher](https://prismlauncher.org), create a Fabric instance, and search for mods directly in the app. See the [Quick Start Guide](docs/quick-start.md).

## Why Java Edition?

Bedrock (Xbox/mobile) only supports cosmetic skins — you can *look* like a mob but you don't get abilities. Java Edition has full modding support, so you actually transform: fly as a bat, teleport as an enderman, shoot fireballs as a blaze.
